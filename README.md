# bugzzzz PICO-8

A retro arcade game where you play as a sneaky mosquito trying to annoy a sleeper without getting swatted!

## About
Created for the **Save Point Hackathon**, *bugzzzz* is a recreation of a classic game I loved playing as a kid.

## Built With
 **Engine:** PICO-8
 **Language:** Lua

## Controls
 **Left / Right Arrows:** Move mosquito
 **X:** Annoy / Buzz
 **Z:** Start / Select in menu

## How to Play & Win
 **Fill the Bar:** Get close to the sleeper and hold **X** to build up the annoyance bar.
 **Watch Out:** Don't buzz for too long continuously—when the `!` warning appears, retreat immediately before he swats you!
 **Maintain Pressure:** The annoyance bar slowly decays when you stop buzzing, so balance your timing and speed to win.

## Compatibility
Available for **Windows**, **macOS**, **Linux**, **Raspberry Pi**, and **Web Browsers**.
